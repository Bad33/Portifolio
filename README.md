# Nikhil Chaudhary — AI Engineer Portfolio

A complete React/Vite redesign of `chaudharynikhil.com`, focused on evaluated AI systems, explainable ML, research software, and engineering impact.

## What is included

- Dynamic dark/light interface with responsive navigation
- Recruiter-focused AI Engineer positioning and measurable impact
- Four featured project experiences with visible **Launch Interactive Demo** controls
- Full-screen PolicyProof retrieval and provenance explorer
- Full-screen ClaimPilot claims-intelligence workflow using synthetic data
- Sanitized structural load-case interaction inspired by the delivered engineering application
- Simulated Spatial Alert coverage map with radius, threshold, zone inspection, and dispatch interaction
- Research publication filters and Google Scholar access
- Experience timeline, AI engineering capabilities, and live GitHub metadata with fallback content
- Current résumé and custom-domain configuration
- GitHub Pages deployment workflow

## Demo safety and honesty

The portfolio demos are browser experiences designed to explain the projects without requiring hosted backends or private data:

- PolicyProof uses representative evidence previews and accepted aggregate metrics. It does not run the ONNX models in the browser.
- ClaimPilot uses synthetic claims and deterministic content. It sends no data and makes no real insurance decision.
- Structural Analysis uses non-design relative indices and does not expose proprietary formulas.
- Spatial Alert uses simulated points and an abstract city network. It sends no real notification.

## Run locally

```bash
npm install
npm run dev
```

Open the local URL displayed by Vite.

## Production build

```bash
npm run build
npm run preview
```

## Deploy to GitHub Pages

1. Replace the contents of `Bad33/Portifolio` with this project.
2. Push to `main`.
3. Open **Settings → Pages** in GitHub.
4. Select **GitHub Actions** as the source.
5. The workflow in `.github/workflows/deploy.yml` builds and deploys the site.
6. `public/CNAME` preserves `chaudharynikhil.com`.
